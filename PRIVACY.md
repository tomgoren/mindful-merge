# Privacy Policy for Mindful Merge

Last updated: August 13, 2026

Mindful Merge does not collect, store, sell, or transmit personal information or user data to the developer or any third party.

## Page Access

Mindful Merge runs only on GitHub pull request pages matching `https://github.com/*/*/pull/*`. It reads the page's review controls and auto-merge indicators to determine whether to display an inline warning.

When a reviewer selects Approve and the current GitHub view does not contain enough information to determine the auto-merge state, Mindful Merge requests the same pull request's Conversation page from `github.com` using the browser's existing GitHub session. The returned HTML is processed locally in the browser and is not retained.

## Data Handling

Mindful Merge does not:

- Operate a backend or analytics service.
- Store browsing history or extension activity.
- Read or retain review comment contents.
- Collect GitHub credentials, authentication tokens, or personal information.
- Send information to the developer, advertisers, or other third parties.
- Sell or use data for advertising, profiling, lending, or credit decisions.

## Changes

This policy may be updated if the extension's behavior changes. The current policy should remain available at the URL supplied in the Chrome Web Store listing.

## Contact

Questions about this privacy policy can be submitted through the support contact listed on the Chrome Web Store page.
